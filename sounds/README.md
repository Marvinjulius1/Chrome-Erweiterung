# Ambient sound files (optional)

Zenith synthesizes Rain, Forest, Ocean and Wind live with the Web Audio API,
so this folder can stay empty.

To use real recordings instead:

1. Find a license-free recording (for example CC0 on freesound.org or
   pixabay.com/sound-effects) and check its license.
2. Save it here, e.g. `sounds/rain.mp3` (MP3, OGG or WAV; a seamless loop works best).
3. Set `"file": "sounds/rain.mp3"` for that sound in `data/sounds.json`.
4. Reload the extension in `chrome://extensions`.
